# Игры на двоих за одним ПК

Две подборки кооперативных игр для ПК — со скриншотами, описаниями и ссылками в Steam.

- **Разделённый экран** — 29 игр: A Way Out, Portal 2, Baldur's Gate 3, Gears 5, DiRT 5 и другие.
  [Открыть](https://ncuxodejluk-code.github.io/games-for-two/splitfiction-like/split-fiction-like-pc.html)
- **Один экран** — 42 игры: Unravel Two, Overcooked! 2, Streets of Rage 4, PICO PARK 2 и другие.
  [Открыть](https://ncuxodejluk-code.github.io/games-for-two/coop-one-screen/coop-one-screen-pc.html)
- **Главная**: https://ncuxodejluk-code.github.io/games-for-two/

## Что внутри

- Карточки игр: 2 скриншота, краткое описание, теги, число игроков, примерная длительность.
- Навигация по разделам, таблица-шпаргалка, кнопка «наверх», лайтбокс по клику на скриншот.
- Бонусные блоки: игры на общем экране (в сплит-подборке) и PvP-вечеринка (во второй).

## Структура

```
index.html                      — главная со ссылками на обе подборки
splitfiction-like/              — подборка со сплит-скрином
coop-one-screen/                — подборка с общим экраном
```

Страницы статические: без сборки, без зависимостей, работают офлайн — достаточно открыть HTML-файл.

Скриншоты взяты из магазина Steam и принадлежат правообладателям игр.
